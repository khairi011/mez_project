# mez_project
 mezyena
 ecommerce web application
 une application web e-commerce permettant aux clients d’acheter des produits cosmétiques en ligne.Les utilisateurs peuvent consulter les produits, filtrer par catégorie, ajouter des articles au panier et passer une commande (avec ou sans compte).  Un administrateur peut gérer les produits, les catégories et les commandes depuis un tableau de bord sécurisé.
